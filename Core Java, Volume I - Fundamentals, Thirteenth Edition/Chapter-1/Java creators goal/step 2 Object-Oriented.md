# 📘 1.2.2 Object-Oriented – Simple Tamil

## 🔹 1. Object-Orientedன்னா என்ன?

👉 Definition:

👉 “Data (objects) + அதோட behavior (methods)”

👉 Meaning:
👉 program = objects கொண்டு build பண்ணுவது

---

## 🔹 2. Carpenter example (bookல analogy)

👉 Object-oriented carpenter:

👉 🪑 “Chair” மீது focus
👉 tools secondary

👉 Non-OOP carpenter:

👉 🔨 tools மீது focus

---

## 💡 Programmingல இதன் meaning

👉 OOP:

✔ “என்ன object?” (data)
✔ “அது என்ன செய்யும்?” (methods)

👉 Non-OOP:

❌ functions + tools மட்டும் focus

---

## 🔹 3. Java = Fully Object-Oriented

👉 Javaல almost எல்லாம் object

✔ class
✔ object
✔ methods

👉 Example:

```id="9zj0n4"
Car car = new Car();
car.start();
```

👉 Car = object
👉 start() = behavior

---

## 🔹 4. C++ vs Java

👉 Java OOP features = C++ மாதிரி தான்

👉 BUT முக்கிய difference:

### ❌ C++:

👉 Multiple inheritance (complex 😵)

### ✅ Java:

👉 Interfaces use பண்ணும்

👉 simple + safe 👍

---

## 🔹 5. Interfaces (important 🔥)

👉 ஒரு class → multiple behavior add பண்ணலாம்

👉 without complexity

👉 Example idea:

```id="zv2m8q"
class Robot implements Walkable, Talkable
```

👉 இது Java design brilliance 💥

---

## 🔹 6. Runtime introspection

👉 Java special feature:

👉 runtime-ல் object info check பண்ணலாம்

👉 (Reflection concept)

👉 Example:
👉 “இந்த object என்ன class?” runtime-ல் தெரியும்

👉 C++-க்கு compare பண்ணா:
👉 Java powerful 🔥
