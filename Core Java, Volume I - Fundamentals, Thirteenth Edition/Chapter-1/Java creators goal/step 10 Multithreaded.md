# 📘 1.2.10 Multithreaded – Simple Tamil

## 🔹 1. Multithreadingன்னா என்ன?

👉 ஒரே programல
👉 பல tasks **simultaneously (parallel)** run ஆகும்

👉 Example:

```text
ஒரே நேரத்தில்:
- file download
- UI update
- background processing
```

👉 இதுதான் threading 🧵

---

## 🔹 2. Why important? (இப்போ காலம் 🔥)

👉 முன்னாடி:
👉 CPU speed அதிகரிச்சது

👉 இப்போ:
👉 speed இல்ல ❌
👉 cores அதிகம் 😲

👉 இதை explain பண்ணுற concept:
👉 Moore's law

👉 Meaning:
👉 faster CPU இல்லை
👉 multiple cores தான்

👉 அதனால்:
👉 parallel programming தேவை 💥
