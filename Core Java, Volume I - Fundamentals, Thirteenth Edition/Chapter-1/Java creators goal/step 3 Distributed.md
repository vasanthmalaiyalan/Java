# 📘 1.2.3 Distributed – Simple Tamil

## 🔹 1. Distributedன்னா என்ன?

👉 “Networkல இருக்கும் systems-ஓட interact பண்ணுவது”

👉 Meaning:
👉 உன் program → internet மூலம் வேற system-ஐ access பண்ணும்

## 🔹 2. Java என்ன special?

👉 Javaல built-in support இருக்கு:

* 🌐 HTTP

👉 network programming easy 😎
