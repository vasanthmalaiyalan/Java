# 📘 1.2.7 Portable – Simple Tamil

## 🔹 1. Portableன்னா என்ன?

👉 “ஒரு systemல எழுதின code → வேற systemல same-ஆ வேலை செய்யணும்”

👉 No changes ❗ No surprises ❗

---

## 🔹 2. Java vs C/C++ (big difference 💥)

👉 **C / C++**:

👉 data types fixed இல்ல

👉 Example:

* `int` → 16-bit அல்லது 32-bit (compiler decide 😓)

👉 Result:
👉 same code → different behavior 😬

---

👉 **Java**:

👉 everything fixed ✅

👉 Example:

```id="3y9n2k"
int = 32-bit (always)
```

👉 எந்த systemலயும் same result 😎

---

## 🔹 3. Why this matters?

👉 portability problem avoid ஆகும்

👉 Example:

* binary data mismatch ❌
* byte order confusion ❌

👉 Java:
👉 consistent format ✅

---

## 🔹 4. Unicode support 🌍

👉 Java strings:

👉 Unicode format

👉 meaning:
👉 எந்த language textயும் support

👉 Example:

* Tamil
* English
* Chinese

👉 எல்லாம் same codeல work 😄

---

## 🔹 5. Libraries also portable 🔥

👉 Java APIs:

✔ OS-independent

👉 Example:

* File handling
* Database
* Network
* Threads

👉 same code → Windows / Linux / Mac

---
