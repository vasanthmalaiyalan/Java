# 📘 1.2.6 Architecture-Neutral – Simple Tamil

## 🔹 1. Architectureன்னா என்ன?

👉 Computer architecture = CPU type

👉 Examples:

* Intel (x86)
* ARM (mobile)
* AMD

👉 Normally:
👉 ஒரு program → specific CPUக்காக compile ஆகும்

---

## 🔹 2. Java என்ன different?

👉 Java compiler:

👉 direct machine code generate பண்ணாது ❌

👉 Instead:
👉 **bytecode** generate பண்ணும் ✅

---

## 🔹 3. Bytecode என்ன?

👉 Intermediate code

👉 CPU-க்கு specific இல்ல

👉 Example flow:

```text id="u1c4px"
Java Code → Bytecode → JVM → Machine Code
```

👉 இதனால்:
👉 same program → different machines run ஆகும் 😲

---

## 🔹 4. JVM role 💻

👉 Java Virtual Machine (JVM):

✔ bytecode interpret பண்ணும்
✔ machine code-ஆ convert பண்ணும்

👉 எந்த systemல JVM இருக்குன்னா:
👉 Java program run ஆகும்

---

## 🔹 5. “Architecture-Neutral” meaning

👉 Program CPU-க்கு dependent இல்ல ❗

👉 compile once
👉 anywhere run

👉 இதுவே:

```text id="g7m2qz"
Write Once, Run Anywhere (WORA)
```

---

## 🔹 6. இது new idea இல்ல

👉 இந்த concept முன்பே இருந்தது

👉 languages:

* Lisp
* Smalltalk
* Pascal

👉 ஆனா Java தான் popular பண்ணியது 🔥

---

## 🔹 7. Performance issue 😅

👉 Problem:

👉 Bytecode → interpret பண்ணும் போது
👉 speed குறைவு

---

## 🔹 8. Solution 💥 (JIT Compiler)

👉 Java use பண்ணும்:

👉 **JIT (Just-In-Time compilation)**

👉 என்ன பண்ணும்?

✔ frequently used code → machine code convert
✔ runtimeல optimize

👉 Result:
👉 fast execution ⚡

---

## 🔹 9. Security advantage 🔐

👉 JVM:

✔ code behavior check பண்ணும்
✔ unsafe instructions block

👉 இதனால்:
👉 extra security layer 😎
