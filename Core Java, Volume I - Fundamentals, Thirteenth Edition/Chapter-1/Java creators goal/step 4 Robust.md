# 📘 1.2.4 Robust – Simple Tamil

## 🔹 1. Robustன்னா என்ன?

👉 “Strong + reliable program”

👉 Meaning:
👉 crash ஆகாமல், errors handle பண்ணி, stable-ஆ run ஆகும்

---

## 🔹 2. Java goal 💪

👉 Java design:

✔ possible problems early-ஆ detect பண்ணும்
✔ runtimeல check பண்ணும்
✔ error-prone situations avoid பண்ணும்

👉 Result:
👉 **less bugs, more stability**

---

## 🔹 3. Compiler advantage 🔥

👉 Java compiler:

👉 error-ஐ **compile timeலேயே detect பண்ணும்**

👉 Example:

```id="7k1x3v"
int x = "hello"; // error
```

👉 Java:
❌ compile ஆகாது

👉 C/C++ல:
👉 சில errors runtimeல தான் வரும் 😓

---

## 🔹 4. Biggest difference 💥 (முக்கியம்)

👉 Java vs C/C++:

### ❌ C/C++

👉 pointers use பண்ணுவாங்க
👉 memory overwrite chance 😵
👉 data corrupt ஆகும்

---

### ✅ Java

👉 direct pointer access இல்லை ❗
👉 safe pointer model

👉 Result:
👉 memory corruption almost impossible 😲

---

## 🔹 5. Memory safety 🧠

👉 Java:

✔ automatic garbage collection
✔ no manual memory free
✔ no dangling pointers

👉 இதனால்:
👉 crashes குறைவு

---

## 🔹 6. Runtime checking

👉 Java runtime:

✔ array bounds check
✔ null check
✔ type check

👉 Example:

```id="8t0m2q"
int[] arr = new int[5];
arr[10] = 1; // error
```

👉 Java:
👉 exception throw பண்ணும்

👉 silent bug இல்லை ❗

---

## 🔹 7. Real developer experience 😅

👉 C/C++ developers:

👉 pointer bug debug பண்ண
👉 hours / days waste 😓

👉 Java:
👉 அந்த headache இல்ல 😄
