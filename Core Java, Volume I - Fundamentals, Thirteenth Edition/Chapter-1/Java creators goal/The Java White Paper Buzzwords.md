# 📘 1.2 Java “White Paper” Buzzwords (Tamil)

👉 Java creators (like James Gosling) define பண்ணின goals 👇

---

## 🔹 1. Simple

👉 Java easy-ஆ use பண்ணலாம்

✔ C++ மாதிரி complex இல்லை
✔ pointers இல்ல
✔ memory automatic (GC)

👉 Meaning:
👉 “Less confusion, more productivity”

---

## 🔹 2. Object-Oriented

👉 Everything = object

✔ class
✔ object
✔ inheritance

👉 Real-world modeling easy

---

## 🔹 3. Distributed

👉 Network-based applications support

✔ Internet apps
✔ APIs
✔ remote systems connect

👉 Example:
👉 Web services

---

## 🔹 4. Robust

👉 Strong + reliable

✔ Error handling (exceptions)
✔ Memory safety

👉 Crash ஆக chance குறைவு

---

## 🔹 5. Secure 🔐

👉 Built-in security

✔ bytecode verification
✔ sandbox model

👉 Viruses / unsafe code avoid

---

## 🔹 6. Architecture-Neutral

👉 CPU dependent இல்லை

✔ Intel / ARM → same bytecode

👉 compile once → anywhere

---

## 🔹 7. Portable

👉 OS independent

✔ Windows
✔ Linux
✔ Mac

👉 JVM இருந்தா போதும்

---

## 🔹 8. Interpreted

👉 Java code → bytecode → JVM run

👉 Direct machine code இல்லை

👉 Advantage:
👉 portability

---

## 🔹 9. High Performance ⚡

👉 ஆரம்பத்தில் slow இருந்தது

👉 இப்போ:
✔ JIT compiler
✔ optimized runtime

👉 near native speed

---

## 🔹 10. Multithreaded 🧵

👉 Multiple tasks parallel

✔ threads support built-in

👉 Example:
👉 Web server → many users handle

---

## 🔹 11. Dynamic

👉 Runtime-ல் behavior change

✔ class loading
✔ reflection

👉 flexible system
