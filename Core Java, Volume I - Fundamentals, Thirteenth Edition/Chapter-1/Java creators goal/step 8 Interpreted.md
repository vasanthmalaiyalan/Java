# 📘 1.2.8 Interpreted – Simple Tamil

## 🔹 1. Interpretedன்னா என்ன?

👉 Program → line-by-line execute பண்ணுவது

👉 Java caseல:

```text
Java Code → Bytecode → JVM (Interpreter) → Run
```

👉 JVM bytecode-ஐ read பண்ணி execute பண்ணும்

---

## 🔹 2. Java எப்படி work ஆகுது?

👉 Step-by-step:

1. `.java` file → compile → bytecode (`.class`)
2. JVM → bytecode interpret பண்ணும்
3. program run ஆகும்

👉 Meaning:
👉 machine-specific code இல்லாமல் run ஆகும் 😎

---

## 🔹 3. முக்கிய advantage 💥

👉 Interpreter use பண்ணதால்:

✔ linking simple
✔ program changes fast test பண்ணலாம்
✔ development flexible

👉 small change → immediately run
