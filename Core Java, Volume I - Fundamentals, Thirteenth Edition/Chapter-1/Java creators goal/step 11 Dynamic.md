# 📘 1.2.11 Dynamic – Simple Tamil

## 🔹 1. Dynamicன்னா என்ன?

👉 “Program run ஆகும் போது behavior change ஆகும் ability”

👉 Meaning:
👉 compile time மட்டும் இல்ல
👉 runtimeலவும் adapt ஆகும் 😎

---

## 🔹 2. Java எப்படி dynamic?

### ✔ Libraries evolve ஆகலாம்

👉 புதிய methods add பண்ணலாம்
👉 existing code break ஆகாது

👉 backward compatibility strong 💪

---

### ✔ Runtime type info (Reflection) 🔍

👉 program run ஆகும் போது:

👉 object என்ன type?
👉 என்ன methods இருக்கு?

👉 check பண்ணலாம்

👉 Example idea:

```id="l7q3mf"
obj.getClass().getMethods();
```

👉 runtime-ல inspect 😲

---

👉 Java easy-ஆ handle பண்ணும்
