# 📘 1.4 A Short History of Java (Simple Tamil)

## 🔹 1. Starting (1991) – Green Project 🌱

👉 Java ஆரம்பம்:

* James Gosling
* Patrick Naughton

👉 Company:

* Sun Microsystems

👉 Goal:
👉 small devices (TV box etc.)க்கு language create பண்ண

👉 project name:
👉 **Green Project** 

---

## 🔹 2. First Idea 💡

👉 Requirements:

✔ small code
✔ low memory
✔ CPU independent

👉 solution:

👉 **Virtual Machine + Bytecode** idea 😎 

---

## 🔹 3. Name change 😄

👉 First name:
👉 **Oak**

👉 problem:
👉 already used

👉 new name:
👉 **Java** ☕

---

## 🔹 4. First Product failure 😅

👉 1992:

👉 product:
👉 “*7” (smart remote control) 

👉 result:
❌ market interest இல்லை

---

## 🔹 5. Continuous struggle 😓

👉 1993–1994:

👉 project sell பண்ண try பண்ணினாங்க

👉 result:
❌ failure

👉 company (First Person Inc.) close ❌ 

---

## 🔹 6. Big turning point 🌐

👉 same time:

👉 Internet + Web grow ஆகுது

👉 browser concept வந்தது

👉 example:

* Mosaic browser

---

## 🔹 7. Smart decision 💥

👉 Java team realize பண்ணியது:

👉 “Webக்கு Java perfect”

👉 features:

* platform independent
* secure
* dynamic

---

## 🔹 8. HotJava Browser 🔥

👉 Java browser create பண்ணினாங்க:

👉 HotJava

👉 web pageல Java code run 😲

## 🔹 9. 1995 – Boom 🚀

👉 SunWorld eventல demo

👉 Java famous ஆனது 💥
