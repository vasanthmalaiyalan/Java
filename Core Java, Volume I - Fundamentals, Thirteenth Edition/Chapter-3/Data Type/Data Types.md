## 🔹 Categories

### 🟦 1. Integer types (4)

👉 whole numbers

* `byte`
* `short`
* `int`
* `long`

---

### 🟩 2. Floating-point (2)

👉 decimal numbers

* `float`
* `double`

---

### 🟨 3. Character (1)

👉 single character

* `char`

👉 Unicode support 🌍

### 🟥 4. Boolean (1)

👉 true / false

* `boolean`
