# 📘 `greeting.length()` என்ன?

👉 `length()` என்பது:

👉 **Javaல already இருக்கும் pre-built method** ✅

👉 இது belongs to:

👉 String

---

# 🔹 Simple explanation

```java
String greeting = "Welcome to Core Java!";
int len = greeting.length();
```

👉 `length()` என்ன பண்ணும்?

👉 stringல உள்ள **characters count** return பண்ணும்

---

## 🔢 Example

```java
String greeting = "Hello";
System.out.println(greeting.length());
```

👉 Output:

```text
5
```

👉 because:

```
H e l l o → 5 characters
```

---

# 🔹 Important concept (மிக முக்கியம் ❗)

👉 Javaல:

👉 `String` = object

👉 அதனால:

👉 methods use பண்ணலாம்

```text
object.method()
```

👉 இங்க:

```text
greeting.length()
```

---

# 🔹 Methodன்னா என்ன?

👉 Method = function

👉 but class உள்ள function

👉 example:

* `length()`
* `toUpperCase()`
* `charAt()`

---

# 🔹 `length` vs `length()` (confusion avoid பண்ணு ⚠️)

👉 Stringக்கு:

```java
greeting.length() ✅ (method)
```

---

👉 Arrayக்கு:

```java
arr.length ❗ (variable, method இல்ல)
```

---
